# Bello Terminal (demo)

A retro green-screen terminal with a little robot that reacts to the mood of your message: hearts for love, glasses for work, a sweat drop for stress.

**Live:** https://bello-terminal-demo.vercel.app

The real Bello Terminal is a private, real-time messaging app I made for me and my boyfriend. This is a public demo of it: nothing you type is sent or saved, and the replies are pre-written.

Everything is in `index.html` (HTML, CSS and JavaScript, no libraries). Open it in a browser to run it.

Made by [Vivienne Le](https://vivienne-le.vercel.app).
